Git刚开始练习时候，推荐就是一开始从命令开始熟悉，然后命令熟悉差不多了，要做项目，就使用IDE上那些自带的git工具去操作就行了，然后剩下的就是练习

git初始化本地仓库命令：
git init


仓库底部README文件应该知道吧

初始化本地仓库完成就是要添加文件到git本地仓库中了


我这里创建了是一个README自述文件，然后我现在要添加到本地仓库中

git add 文件地址

添加进来后，只是文件存储在git一个缓存区，也是git文件对象，还没有正式被存储到本地仓库中，还需要提交到本地仓库中

在正式提交到本地仓库之前，要检查几个git关键参数有没有初始化配置好，用户名、邮箱，这两个是最基础的配置

git config --list 查看已经配置的配置


git config --global

你这里配置，那我不说了

然后就是要将添加到缓存的文件，推送到本地仓库中

git commit -m “提交原因”

然后这样，这个代码文件就推送到本地仓库中了。

因为这里暂时还是本地，没有添加远程仓库，现在就是添加远程仓库


添加远程仓库地址 使用ssh
git remote add origin 远程仓库地址

然后就是将本地仓库 push 推送到远程仓库中

git push

现在我只添加test1文件，不添加test2文件 然后推送到远程仓库上去

就是直接三条命令

git add test1
git commit -m "添加test1文件"

现在我要添加所有我创建的或者更新的文件，然后推送到远程仓库上去

git add --all
git commit -m "添加所有文件"
git push
